Pax Buttonica · hardware

Flasher

Plug an Atom into this laptop with a data cable, find out what it is, and put the latest hub or button firmware on it. Nothing to install: the browser does the flashing. Chrome or Edge only. Close any other tab that has the hub connected first.

1 · Who is this?

Plug one in and ask.
A button answers with its id and blinks white, so you can tell which one is on the cable. A hub answers as a hub. A brand-new Atom says nothing (it only has the factory firmware), which is also an answer.

2a · Make it a hub

The one that stays on the laptop's USB. Only one of these.

This browser can't flash; use Chrome or Edge.

2b · Make it a button

The ones in the shells, with a key and a hex. Same firmware on every button; they tell themselves apart by their own ids.

This browser can't flash; use Chrome or Edge.

How it goes

  1. Plug the Atom in. Click Ask the Atom and pick the port called "USB JTAG/serial debug unit" (if two are listed, either works). It tells you what's on it now.
  2. Click Connect under hub or button, pick the same port, choose Install in the dialog, wait for "Installation complete" (about 20 seconds), close it.
  3. Click Ask the Atom again. It should now answer with the new version. Buttons blink white while they answer.
  4. Do the hub first after a firmware change, then each button. A button flashed before its hub only reaches it by luck.
If the install fails to connect, unplug and replug the Atom and try again; if it says the port is busy, another tab has it. The terminal alternative is firmware/flash.sh hub or firmware/flash.sh button.
